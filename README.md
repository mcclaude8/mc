# Emberhold Forge

- `index.html` — playable game (open in a browser). Adds a music on/off setting and two late-game metals (Frostsilver, day 11; Starmetal, day 18) to the original.
- `original/Emberhold_Forge1.html` — the original file.
- `emberhold/` — work in progress: the game split into per-system source files for the planned open-world upgrade. Not finished and does not build yet.
